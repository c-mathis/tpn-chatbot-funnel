# Tax Peace Now - Standalone Chatbot Backup

This directory contains a complete backup of the standalone chatbot functionality before adding landing page content.

## Files:
- `chatbot-standalone.html` - Main chatbot interface (standalone version)
- `wizard.js` - Chatbot logic and form handling
- `style.css` - Complete styling for chatbot
- `tpn-character-transparent.png` - Kirk character image
- `thank-you.html` - Thank you page after form submission

## Usage:
To use this as a standalone chatbot:
1. Ensure all files are in the same directory structure
2. Update asset paths in HTML if needed
3. Deploy to any web server

## Features:
- 6-step tax resolution questionnaire
- Kirk character branding
- Google Sheets integration
- Meta Pixel and Google Ads tracking
- Mobile-responsive design
